## 🎯 CONVERSION PATTERNS

### Express → Next.js

Express routes in `index.js`:
```javascript
app.get('/api/packages', async (req, res) => { ... })
```

Becomes Next.js API route at `pages/api/packages.js`:
```javascript
export default async function handler(req, res) { ... }
```

EJS views in `views/*.ejs` become React pages in `pages/*.js`
